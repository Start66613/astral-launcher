## 状态与动效

- `startLaunch` 返回真实 Task；queued/running 展示实际 stage/label，total 未知使用非确定进度，无整体假百分比。
- Task.done 只表示进程创建；等待查询 session，不能宣布已进入游戏。
- session.state=running 才显示“游戏进程运行中”；当前核心不确认游戏窗口或主菜单。
- 匹配 instanceId+sessionId 的 game-exit 或 exited 会话才退出，旧事件不能覆盖新会话。
- 失败立即停止活动动效，保留错误与详情，复制和重试有真实操作；健康检查失败显示原因，不在 UI 改成健康。
- 刷新先订阅，再读取任务、当前版本和会话；复用现有 useInstances 与 mergeTask 的 revision/终态规则，绝不从 localStorage PID 恢复运行态。
- 三种启动效果在正式设置中均可选择，真实流程共用一个 LiveLaunch；约500ms入场不阻挡操作。任务列表显示排队/下载/校验/安装/完成/失败的实际阶段。

游戏安装当前是前端串接既有安装→创建→可选Loader任务，全部 done 后重读 health 才展示完成。它不是 Rust 原子安装计划，关窗/重启后的续接和回滚仍需核心扩展。
