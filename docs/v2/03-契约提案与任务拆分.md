## 1. 对 Codex 提案的总体结论

他们的 DTO 设计基本可以直接采用，我做 5 处调整：

| # | Codex 提案 | 我的调整 | 原因 |
|---|---|---|---|
| 1 | `prepare_game_install({request})` | 保留，`request` 内增加 `memoryMb?` | 实例创建时就要定内存 |
| 2 | `start_game_install({planId, revision})` | 保留 | — |
| 3 | `get_component_catalog` 合并 loader/shader/optional | **保留合并**，但额外提供 `list_loader_builds` 单一职责接口 | 二级页要"全部 build 列表"，catalog 只给推荐 |
| 4 | `list_resource_files({target})` 里带 `target` | **去掉** `target`，文件列表与目标无关 | 目标只影响"装到哪"，不影响"有哪些文件" |
| 5 | `Task` 需要跨重启 | 不加新状态枚举，用 `error.code = "INTERRUPTED"` | 不破坏前端已实现的 `TaskState` 联合 |

## 2. P0 契约（本轮实现）

### 2.1 加载器构建列表

```ts
type LoaderKind = "fabric" | "quilt" | "forge" | "neoforge";

interface LoaderBuild {
  id: string;                 // "fabric-0.16.9" / "forge-47.2.0"
  kind: LoaderKind;
  version: string;            // loader 自身版本
  mcVersion: string;          // 适配的 MC 版本
  stability: "stable" | "beta" | "alpha" | "unknown";
  recommended: boolean;
  publishedAt: string | null;
  available: boolean;
  unavailableReason: string | null;
}

// list_loader_builds({ gameVersion, kind }): LoaderBuild[]
```

- 数据源：Fabric/Quilt `meta.*`；Forge `maven-metadata.xml` + `promotions_slim.json`；NeoForge `maven.neoforged.net`。
- **无 stable 字段一律 `unknown`，不推断。**
- `available=false` 表示"查到了但不适配/暂不支持"，与"查询失败"（抛 `NETWORK`）区分。

### 2.2 安装计划

```ts
interface ComponentSelection { provider: "modrinth" | "official"; projectId: string; versionId: string }

interface GameInstallRequest {
  name: string;
  gameVersion: string;
  loader: { kind: LoaderKind; version: string } | null;
  shaderSupport: ComponentSelection | null;
  optionalComponents?: ComponentSelection[];
  memoryMb?: number;
}

interface PlannedFile {
  id: string; displayName: string; sizeBytes: number | null;
  role: "required" | "optional";
  action: "add" | "reuse" | "replace";
  relativePath: string;
}

interface PlanIssue { code: string; message: string; blocking: boolean; componentId?: string }

interface GameInstallPlan {
  planId: string; revision: number; expiresAt: string;
  request: GameInstallRequest;
  target: { proposedInstanceId: string; displayPath: string; isolated: true };
  files: PlannedFile[];
  issues: PlanIssue[];
  downloadBytes: number | null;   // 未知 = null，不填 0
}

// prepare_game_install({ request }): GameInstallPlan
// start_game_install({ planId, revision }): Task   // result: { kind:"game-install", instance }
```

行为约定：

- `planId` 由 Rust 生成，15 分钟过期；执行时校验 `revision`，不匹配抛 `PLAN_EXPIRED`。
- 计划阶段**只读**：不建目录、不下载。
- 执行时重算文件状态；与计划不一致抛 `TARGET_CHANGED`。
- 失败时保留 `instances/<id>/` 但标记 `health.ok=false`，**不删除**，并清理 `.part` 文件。

### 2.3 存档目标（数据包用）

```ts
interface WorldTarget {
  worldId: string;          // Rust 生成，稳定、非显示名
  displayName: string;      // "Expedition_07"
  dir: string;
  lastModified: string;
  sizeBytes: number;
  gameVersion: string | null;
}

// list_target_worlds({ instanceId }): WorldTarget[]
```

- `worldId` = `w_<sha1(目录名)[..8]>`，Rust 内部映射回真实目录；前端禁止用名字拼路径。

### 2.4 任务系统改造（不加枚举）

```ts
interface Task {
  // …现有字段保持不变…
  cancelling: boolean;      // 新增：已请求取消、等待 worker 停止
  bootId: string;           // 新增：进程启动标识，用于识别"上次未结束"
}
```

- `cancel_task({taskId})` → `{accepted: boolean}`；`accepted=true` 后 `cancelling=true`，
  worker 真正停下才置 `state="cancelled"`。
- 重启后：上次 `running/queued` 的任务恢复为 `state="error"` + `error.code="INTERRUPTED"`。
- `retry_task({taskId})` → 新 Task（`retryOf` 指向原任务），仅允许终态为 `error`/`cancelled`。

## 4. 启动阶段枚举（对 Codex 的更新）

现有 `stage` 是自由字符串，**加值不破坏兼容**。V2 计划使用：

| stage | 含义 | 来源 |
|---|---|---|
| `validate` | 校验实例与版本文件 | 自研 |
| `prepare-java` | 探测/准备 Java | portablemc `LoadJvm` |
| `check-files` | 校验依赖库/资源 | portablemc `LoadedAssets`/`LoadedLibraries` |
| `download` | 补文件 | `DownloadProgress` |
| `launch` | 拼装命令、起进程前 | 自研 |
| `spawned` | 进程已创建（Task.done） | 自研 |
| `running` | `GameSession.state=running` | session |
| `exited` | `game-exit` | session |
| `failed` | 任一阶段失败 | 自研 |

> **不提供"窗口可见/主菜单就绪"**：Rust 无法可信判断，宁可不给。Codex 若要做启动动画，请以 `spawned → running` 为界，不要用固定时长假装完成。

## 5. 需要和 Codex 协调的 6 件事

1. **CSP 收紧会打挂远程图标**：我准备设 `img-src 'self' data: blob: https://cdn.modrinth.com`，
   如果界面还加载别的域（背景图、字体 CDN），请把域名清单给我；否则收紧后图标全白。
2. **`Task.cancelling` / `bootId` 是新字段**：`mergeTask` 不受影响，但类型要补。
3. **`INTERRUPTED` 复用 `error`**：界面不要只按 `state` 判断，要读 `error.code`。
4. **`worldId` 不能当显示名**：数据包安装必须传 `worldId`，UI 需要从 `list_target_worlds` 取。
5. **`planId` 有 15 分钟有效期**：UI 需要在过期后重新 `prepare`，不能复用旧计划。
6. **Forge/NeoForge 未完成前**，`list_loader_builds` 对这两个 kind 返回 `available=false` 并给原因，UI 应置灰而不是报错。
