## 5. 未验证 / 阻塞（不夸大）

| 项 | 原因 |
|---|---|
| **MSA 微软登录** | 需用户自备 Azure 应用 ID；令牌加密（DPAPI）未做 |
| **CSP 视觉验证** | 配置已收紧并通过构建，但本机窗口焦点被占，截不到自绘窗口；需合并出包确认 |
| **`cargo test`** | 测试二进制加载期失败（0xC0000139），已排除 6 种常见原因，见 `10-cargo-test-调查.md` |
| **新命令的前端接入** | 桥接代码块已写好，但共享文件 `bridge.ts` 尚未修改（需双方协调） |
| **依赖版本约束匹配** | 目前取第一个兼容版本，未做 semver 约束 |
| **JDK 删除/清理** | 刻意未做（不可逆操作需用户明确触发） |
| **Forge/NeoForge 之外的加载器组合** | e.g. NeoForge + 1.20.1 安装失败（上游安装器问题），只保证列出版本 |

## 6. 复现方式

```powershell
# 自检
& "$env:USERPROFILE\Astral\Astral-core.exe" --selftest
Get-Content "$env:TEMP\astral-selftest.json"

# 命令注册校验
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/check-commands.ps1

# 真机安装 / 启动（示例）
$env:ASTRAL_LIVE_FORGE = "forge|1.20.1|47.2.0|D:\Astral\forge-test"
$env:ASTRAL_LIVE_LAUNCH = "D:\Astral\forge-test|1.20.1|fabric|0.16.9"
& "$env:USERPROFILE\Astral\Astral-core.exe" --selftest
```

> 所有真机测试都在 `D:\Astral\*` 隔离目录进行，未触碰用户的 `%APPDATA%\.minecraft`。
