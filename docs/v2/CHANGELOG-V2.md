## 二、新增能力

### 下载与安全
- 来源白名单（14+ 主机）、`https` 强制、拒绝 userinfo / IP / 内网
- `.part` 原子替换、SHA1/SHA256/SHA512 校验、路径 canonicalize 防逃逸
- 连接阶段重试（TLS 抖动 3 次）；Tauri CSP 收紧（`38c0df7`）

### 实例 / 会话 / 任务
- 实例：托管目录、健康检查（沿 `inheritsFrom` 查 jar/库/索引）、原子写入
- 会话：pid 对账、`reconciled`、`exitKnown` 区分未知退出码
- 任务：真取消（两阶段）、跨重启 `INTERRUPTED`、去重、重试、`phase` + `stageLabel`

### 安装
- 两段式计划 `prepare_game_install` / `start_game_install`，失败回滚
- 四类加载器全部真实安装 + 启动：Fabric / Quilt / Forge / NeoForge
- 安装器健壮性：`launcher_profiles.json`、JVM 代理参数、失败重试、半成品清理

### 资源与生态
- Modrinth 项目/文件查询、定向安装（mod/资源包/光影包/数据包）
- 必需依赖自动补装，缺依赖明确报错
- 模组更新检查 + 原子替换（先新后旧）
- 光影支持组件目录（Iris / Oculus / OptiFine 明确不可自动装）

### 整合包
- `.mrpack` 解析与安装（zip-slip 防护、512 MiB 上限、回滚）
- `.mrpack` 导出（Modrinth 可查的写 index，其余进 overrides），导出可回读

### Java 与日志
- Java 扫描（4 类来源，按 `javaVersion` 推荐）
- Adoptium JDK 自动下载（SHA256、安全解压、不改系统）
- 日志读取（尾部 4 MiB、行数上限）+ 本机脱敏预览（token/邮箱/用户目录/IP）
