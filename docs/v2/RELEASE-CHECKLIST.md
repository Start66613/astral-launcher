# 发布检查清单

> 这份清单的目的是让"能不能发"变成一个可以逐条打勾的事情，而不是凭感觉。
> 每次发版前把下面全部走一遍，任何一条不过就不发。

## 0. 前置：产物形态还没定

**当前阻塞**：发布产物是「安装包（NSIS / MSI）」还是「免安装 zip」还没定。
两种形态的检查项不同（安装包要验卸载、注册表、开始菜单；免安装要验解压即用、
便携配置）。定了之后再补对应章节。

在产物形态定下来之前，**不要打 tag、不要发布**。

- [ ] 前端 `tsc --noEmit` 与 `vite build` 通过

## 2. 功能冒烟（手动，隔离目录）

在 `D:\Astral\release-test` 这样的隔离目录里做，**不要用真实 `.minecraft`**。

- [ ] 全新安装一个原版版本（如 1.20.1），能启动到主菜单
- [ ] 装一个加载器（Fabric / Forge 各一次），能启动
- [ ] 装一个 Mod（含依赖），依赖自动补齐，游戏能起来
- [ ] 装一个资源包 / 光影包，游戏里能看到
- [ ] 导入一个 `.mrpack`，装完能启动
- [ ] 断网启动：版本列表能显示上次缓存，且**标明是缓存**
- [ ] 下载大文件时点取消，确认几百毫秒内停下，`.part` 保留
- [ ] 取消后再下同一个文件，确认是续传（进度从断点继续，不是从 0）
- [ ] 删除一个实例 → 回收站能看到 → 恢复 → 存档还在
- [ ] 备份一个存档 → 改点东西 → 恢复 → 确认能回到备份点，且旧存档留底
- [ ] 故意删掉一个 library → 文件检查能查出来 → 修复 → 能启动
- [ ] 制造一次崩溃（比如给个坏 mod）→ 诊断能给出可读的原因

## 3. 安全

- [ ] 所有下载地址都在白名单内（`net::ALLOWED_HOSTS`）
- [ ] 重定向到非白名单域名会被拒绝（自检已覆盖，仍手动抽查一次）
- [ ] 解压 zip 的路径穿越被拒绝（自检已覆盖）
- [ ] 所有破坏性操作（清空缓存/删备份/删 JDK/清回收站）都要求 `confirm: true`
- [ ] 没有任何地方无确认删除玩家存档、mods、config
- [ ] 日志脱敏生效（邮箱、IP、token、用户目录都被替换）
- [ ] 诊断**不上传**任何内容（`localOnly: true`）

## 4. 自动更新（**当前不开放**）

任务书要求：**没有签名密钥、没有可信源，不得开放自动下载安装。**

- [ ] ❌ 签名方案未定
- [ ] ❌ 可信源未定
- [ ] ❌ 更新包完整性校验方案未定

在以上三项完成前，`updates.rs` 的"检查更新"可以保留（只提示），
但**绝不能**自动下载并执行安装。发布说明里要写清楚这一点。

## 5. 发布说明

- [ ] 列出这一版新增的后端能力（对照 `BACKEND-ROADMAP.md`）
- [ ] 列出已知问题与未完成项（对照 `BACKEND-TEST-REPORT.md` §6）
